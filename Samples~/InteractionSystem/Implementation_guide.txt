Modular Interaction System — Setup & Integration Guide
Complete step-by-step guide to set up, run, and integrate the Modular Interaction System from the UnityMechanicsFramework into your Unity project.

Prerequisites
Unity 2021.3 LTS or later (2022.3 LTS recommended)

TextMeshPro package (usually included by default in Unity)

Step 1: Create the Interactable Layer
Go to Edit > Project Settings > Tags and Layers.

In the "Layers" section, find an empty User Layer slot (e.g., Layer 6).

Name it Interactable.

Note: Every interactable object in your game must be assigned to this layer.

Step 2: Set Up the Player
Create an empty GameObject: GameObject > Create Empty.

Name it Player.

Add the following components:

SpriteRenderer (assign any sprite — a square works fine).

Rigidbody2D (set Gravity Scale to 0 for top-down, or leave for platformer).

BoxCollider2D.

InteractionController_UMFOSS (from Runtime/Interaction/).

Configure InteractionController_UMFOSS in the Inspector:

Detection Mode: OverlapCircle

Interaction Radius: 2.5

Interactable Layer: select Interactable

Selection Mode: Nearest

Require Hold: false (unticked)

Interact Key: E

Gamepad Button: Submit

(Optional) Add a simple movement script (DemoPlayerMovement.cs) to walk around.

Step 3: Set Up the Interaction Prompt UI
Create a Canvas: GameObject > UI > Canvas.

Set the Canvas Scaler to Scale With Screen Size, 1920x1080.

Create the prompt panel:

Right-click Canvas > UI > Panel. Name it PromptPanel.

Anchor it to the bottom-center. Set size to ~350x80.

Set the Image alpha to ~180 for slight transparency.

Inside PromptPanel, create the text:

Right-click PromptPanel > UI > Text - TextMeshPro. Name it PromptLabel.

Set text to "Press E to interact", center align, white color, font size 24.

Inside PromptPanel, create a progress bar:

Right-click PromptPanel > UI > Slider. Name it HoldProgressBar.

Delete the Handle Slide Area child object.

Set Min: 0, Max: 1, Value: 0. Untick Interactable.

Anchor to the bottom and stretch horizontally.

Add the InteractionPrompt_UMFOSS component to PromptPanel:

Prompt Panel: drag PromptPanel here.

Prompt Label: drag PromptLabel here.

Hold Progress Bar: drag HoldProgressBar here.

Step 4: Create Interactable Objects
All objects below must have their Layer set to Interactable.

OBJECT 1 — DOOR (Instant, single-use)

Create a square sprite GameObject, name it Door.

Add a BoxCollider2D.

Add the DemoInteractableDoor component.

Drag its SpriteRenderer into the script's reference slot.

OBJECT 2 — NPC (Instant, repeatable)

Create a sprite GameObject, name it NPC.

Add a BoxCollider2D.

Add the DemoInteractableNPC component.

Create a child Text - TextMeshPro for the name tag, and drag it into the script's Name Tag Object field.

OBJECT 3 — ITEM PICKUP (Instant, single-use)

Create a small sprite GameObject, name it HealthPotion.

Add a CircleCollider2D.

Add the DemoInteractablePickup component. Set Item Name to "Health Potion".

OBJECT 4 — GENERATOR (Hold to interact)

Create a sprite GameObject, name it Generator.

Add a BoxCollider2D.

Add the DemoInteractableGenerator component. Set the Sprite Renderer reference.

Note: To test this, you must temporarily set Require Hold = true and Hold Duration = 2 on the Player's InteractionController.

Step 5: Add Demo UI Display
On the Canvas, add two Text - TextMeshPro objects:

InventoryLabel — anchored top-left.

DetectionModeLabel — anchored top-right.

Create an empty GameObject named DemoManager.

Add the DemoInventoryDisplay component:

Assign the labels and drag the Player into the Controller field.

Add the DemoDetectionModeSwitcher component:

Assign the Player to the Controller field, set Switch Key to Tab, and assign the Mode Label.

Step 6: Test the Scene
Press Play.

Move the player with WASD or arrow keys.

Walk toward each object:

Door: highlights, shows "Press E to open". Press E to open.

NPC: shows name tag and "Press E to talk". Press E to log dialogue in the Console.

Pickup: floats and shows item name. Press E to collect (updates inventory UI).

Generator: (Requires Hold mode) Hold E to fill the progress bar and activate.

Press Tab to switch detection modes dynamically.

Step 7: Integrate IInteractable Into Your Own Mechanic
This is the core pattern. Follow these steps to make ANY script in your game interactable. Zero changes to the controller are required.

7.1 — Add the Interface
Include the namespace and add IInteractable_UMFOSS to your MonoBehaviour.

C#
using UnityEngine;
using GameplayMechanicsUMFOSS.Interaction;

public class MyCustomChest : MonoBehaviour, IInteractable_UMFOSS
{
    private bool isOpen = false;
7.2 — Implement the Properties
Define the prompt message and priority.

C#
    public string PromptMessage => isOpen ? "" : "Open Chest";
    public int Priority => 0; // Higher number = selected first when overlapping
7.3 — Implement CanInteract()
Tell the controller if this object is currently usable.

C#
    public bool CanInteract()
    {
        // Only interactable if it hasn't been opened yet
        return !isOpen; 
    }
7.4 — Implement Focus Methods
Determine what happens visually when the player gets close or walks away.

C#
    public void OnFocused()
    {
        // Example: Highlight the chest
        GetComponent<SpriteRenderer>().color = Color.yellow;
    }

    public void OnLostFocus()
    {
        // Example: Revert the highlight
        GetComponent<SpriteRenderer>().color = Color.white;
    }
7.5 — Implement Interact() and CancelHold()
Write the actual gameplay logic.

C#
    public void Interact()
    {
        isOpen = true;
        Debug.Log("Chest opened! Loot granted.");
        GetComponent<SpriteRenderer>().color = Color.gray;
    }

    public void CancelHold()
    {
        // Only used if the player releases the interact key early during a Hold interaction.
    }
}
Final Step: Add your MyCustomChest script to a GameObject, ensure it has a Collider, and set its layer to Interactable. The InteractionController will automatically detect it!
