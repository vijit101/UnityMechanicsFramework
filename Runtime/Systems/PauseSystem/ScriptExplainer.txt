PauseSystem_UMFOSS.cs — Script Explainer
Namespace: GameplayMechanicsUMFOSS.Systems

Overview
- This script provides a centralized pause manager with a small public API: Pause(), Resume(), TogglePause(), IsPaused, and GetPausedTimeScale().
- It preserves existing time manipulation (for example, slow motion) by storing Time.timeScale before pausing and restoring that exact value on resume.
- It optionally pauses all audio globally with AudioListener.pause.
- It publishes events through EventBus so other systems can react without direct references.

Stored timeScale pattern
- On Pause(), the script stores the current Time.timeScale into storedTimeScale, then sets Time.timeScale to 0f.
- On Resume(), it restores Time.timeScale from storedTimeScale (never hardcodes 1.0f).
- This makes pause compatible with bullet time and any other custom time system.

Audio behavior
- If pauseAudio is true, Pause() sets AudioListener.pause = true and Resume() sets it back to false.
- If pauseAudio is false, audio is left untouched while gameplay is paused.

Events and decoupling
- On pause, GamePausedEvent { previousTimeScale } is published.
- On resume, GameResumedEvent { restoredTimeScale } is published.
- On focus loss, ApplicationFocusLostEvent is published.
- On focus gain, ApplicationFocusGainedEvent is published.
- The pause system does not know player, AI, UI, or timer classes; those systems subscribe to these events themselves.

Focus loss handling
- If toggleOnFocusLoss is true and the app loses focus, the script publishes ApplicationFocusLostEvent and pauses (if not already paused).
- On focus return, it only publishes ApplicationFocusGainedEvent.
- It never auto-resumes on focus return. Resume remains a user action.

Unscaled time contract for UI during pause
- Pause only controls scaled game time (Time.timeScale).
- UI that must animate while paused must use Time.unscaledDeltaTime (or equivalent unscaled-time APIs).
- Example:
  - Frozen while paused: position += speed * Time.deltaTime
  - Continues while paused: position += speed * Time.unscaledDeltaTime

Guard clauses and state integrity
- Pause() exits immediately if already paused.
- Resume() exits immediately if not paused.
- This prevents duplicate state transitions and duplicate event firing.
